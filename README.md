# Local Farm - Modern Agricultural Landing Page & Admin Portal

A modern Next.js 16 landing page with Tailwind CSS, Framer Motion animations, and an interactive Admin/Farmer portal inspired by the reference design.

## Features

- **Pixel-Accurate Hero Layout**:
  - **Left Section**: Big catchy headlines ("Your Farm. Your Community. Your Local Farm."), subtext, "Get the App" CTA button, "Learn More" button, and Apple & Google Play download badges with rating proofs.
  - **Center Mockup**: 3D perspective smartphone running Local Farm with live post feeds, organic crop tags, weather widgets, and orbiting animated badges (`🌱 Learn Farming tips`, `👥 Connect with farmers`, `📢 Share your stories`, `💚 Grow together`).
  - **Right Auth & Admin Card**: Toggleable between **Farmer Login** and **Admin Portal Login**, complete with password visibility toggle, remember me, Google SSO button, and live demo launcher.
- **5 Pillars Feature Bar**:
  - `Connect` (Connect with farmers and your community)
  - `Learn` (Discover modern farming tips and agricultural news)
  - `Share` (Share stories, harvest photos, and experiences)
  - `Live` (Join live field streams in real-time)
  - `Safe & Secure` (Encrypted, protected agricultural data system)
- **Interactive Admin Command Center Modal**:
  - Farmer directory & verification status management
  - Agronomy & yield capacity analytics
  - Regional frost & weather broadcast alert dispatcher
- **Extended Sections**:
  - Interactive Agronomy & Marketplace Feature Showcase Tabs
  - Platform Impact & Live Metrics
  - Farmer & Grower Community Testimonials
  - Mobile App Download with QR code
  - Responsive Footer with Agronomy Newsletter Subscription

## Getting Started

### Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### Production Build
```bash
npm run build
npm run start
```
